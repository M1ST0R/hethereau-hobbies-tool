## Hethereau Hobbies Tool v0.3.0

The first versioned desktop release of HHT brings the Owner's Selection automation into a unified, bilingual desktop application for Neverness to Everness.

### Highlights

- **Integrated desktop app** — PySide6 + Qt Quick (QML) interface with English and Russian languages, Light and Dark themes, persistent settings, and an in-app sidebar for the module, Settings, About, and Logs.
- **Owner's Selection automation** — opens the event shop, operates the hammer, tracks challenge income, claims the reward, checks available energy, and repeats the cycle while possible.
- **Adaptive target detection** — reads the current level's income target directly from the game instead of relying on a fixed level table.
- **Screen-aware OCR** — energy is scanned only on the event start menu (the screen with the Start button); income is scanned during the challenge. Independent screenshot checks are used to reject unstable readings.
- **Safer target handling** — hammer input becomes one-click-at-a-time near the target. Once the target is detected, hammer clicks stop and a fresh paired OCR check confirms the threshold before HHT leaves the event.
- **Pause and resume recovery** — the app rechecks the visible counter after resuming and avoids continuing with unconfirmed game state.
- **Configurable controls and diagnostics** — assign your own global hotkeys, inspect the activity log, and use saved OCR / click-target diagnostic captures when troubleshooting.

### Downloads

This release provides three packages:

- **Windows 10/11 x64:** `Hethereau-HHT-Windows-x64-0.3.0.exe` — portable single-file executable with Tesseract OCR bundled. Windows may ask for Administrator approval (UAC).
- **Debian / Ubuntu x86_64:** `hethereau-hobbies-tool_0.3.0_amd64.deb` — installable package for X11; required system dependencies are declared by the package.
- **Linux x86_64:** `Hethereau-HHT-Linux-x86_64-0.3.0.tar.gz` — portable package for X11; install Tesseract OCR separately.

### Notes

- The currently available automation module is **Owner's Selection**. Fishing and other activities are planned for future modules.
- Linux support currently targets **X11** sessions.
- OCR depends on the game's UI scale and screen resolution. Supervise the first run after changing resolution or UI scale.
- HHT is an unofficial community project and is not affiliated with or endorsed by the developers of Neverness to Everness.
